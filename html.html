HTML Básico

O que é HTML?

HTML (HyperText Markup Language) é a linguagem padrão para criar páginas web. Define a estrutura do conteúdo usando um sistema de "marcação" com elementos chamados tags.

Estrutura básica de um documento HTML

Todo documento HTML deve começar com uma declaração de tipo de documento e conter os elementos html, head e body.

<!DOCTYPE html>
<html lang="pt-br">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Minha primeira página</title>
</head>
<body>
    <h1>Olá, mundo!</h1>
    <p>Este é meu primeiro site.</p>
</body>
</html>

Tags HTML básicas

As tags mais comuns usadas para formatar texto e criar estruturas básicas:

<!-- Cabeçalhos -->
<h1>Título principal</h1>
<h2>Subtítulo</h2>
<h3>Cabeçalho nível 3</h3>

<!-- Parágrafos e formatação de texto -->
<p>Este é um parágrafo.</p>
<p>Texto em <strong>negrito</strong> e <em>itálico</em>.</p>

<!-- Listas -->
<ul>
    <li>Item não ordenado 1</li>
    <li>Item não ordenado 2</li>
</ul>

<ol>
    <li>Primeiro item ordenado</li>
    <li>Segundo item ordenado</li>
</ol>

<!-- Links -->
<a href="https://www.exemplo.com">Visite Exemplo.com</a>

<!-- Imagens -->
<img src="imagem.jpg" alt="Descrição da imagem">

HTML Intermediário

Formulários HTML

Os formulários permitem a coleta de dados dos usuários e são essenciais para criar interações em páginas web.

<form action="/processar" method="post">
    <div>
        <label for="nome">Nome:</label>
        <input type="text" id="nome" name="nome" required>
    </div>
    
    <div>
        <label for="email">Email:</label>
        <input type="email" id="email" name="email" required>
    </div>
    
    <div>
        <label for="mensagem">Mensagem:</label>
        <textarea id="mensagem" name="mensagem" rows="4"></textarea>
    </div>
    
    <div>
        <label>
            <input type="checkbox" name="inscricao"> 
            Inscrever-me no newsletter
        </label>
    </div>
    
    <button type="submit">Enviar</button>
</form>

Tabelas HTML

As tabelas são usadas para organizar dados em linhas e colunas.

<table>
    <thead>
        <tr>
            <th>Nome</th>
            <th>Idade</th>
            <th>Profissão</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>Ana Silva</td>
            <td>28</td>
            <td>Desenvolvedora</td>
        </tr>
        <tr>
            <td>Carlos Santos</td>
            <td>35</td>
            <td>Designer</td>
        </tr>
    </tbody>
</table>

HTML semântico

Os elementos semânticos fornecem significado à estrutura da página, melhorando acessibilidade e SEO.

<header>
    <h1>Meu Site</h1>
    <nav>
        <ul>
            <li><a href="#">Início</a></li>
            <li><a href="#">Sobre</a></li>
            <li><a href="#">Contato</a></li>
        </ul>
    </nav>
</header>

<main>
    <section>
        <h2>Sobre nós</h2>
        <p>Informações sobre a empresa.</p>
    </section>
    
    <article>
        <h2>Nosso último projeto</h2>
        <p>Detalhes sobre o projeto.</p>
    </article>
    
    <aside>
        <h3>Posts relacionados</h3>
        <ul>
            <li><a href="#">Artigo 1</a></li>
            <li><a href="#">Artigo 2</a></li>
        </ul>
    </aside>
</main>

<footer>
    <p>© 2025 Meu Site. Todos os direitos reservados.</p>
</footer>

HTML Avançado

SVG e Canvas

HTML5 permite a criação de gráficos vetoriais (SVG) e desenhos baseados em pixels (Canvas).

<!-- SVG (Scalable Vector Graphics) -->
<svg width="200" height="200">
    <circle cx="100" cy="100" r="80" fill="blue" />
    <rect x="60" y="60" width="80" height="80" fill="red" />
</svg>

<!-- Canvas (para gráficos dinâmicos) -->
<canvas id="meuCanvas" width="200" height="200"></canvas>
<script>
    const canvas = document.getElementById('meuCanvas');
    const ctx = canvas.getContext('2d');
    
    // Desenhar um retângulo
    ctx.fillStyle = 'green';
    ctx.fillRect(50, 50, 100, 100);
    
    // Desenhar um círculo
    ctx.beginPath();
    ctx.arc(100, 100, 50, 0, 2 * Math.PI);
    ctx.fillStyle = 'purple';
    ctx.fill();
</script>

Elementos de mídia HTML5

HTML5 introduziu elementos nativos para áudio e vídeo, eliminando a necessidade de plugins.

<!-- Vídeo -->
<video controls width="400">
    <source src="video.mp4" type="video/mp4">
    <source src="video.webm" type="video/webm">
    Seu navegador não suporta o elemento de vídeo.
</video>

<!-- Áudio -->
<audio controls>
    <source src="audio.mp3" type="audio/mpeg">
    <source src="audio.ogg" type="audio/ogg">
    Seu navegador não suporta o elemento de áudio.
</audio>

Web Components

Web Components permitem criar elementos HTML personalizados reutilizáveis.

<!-- Definição de um web component -->
<template id="meu-botao-template">
    <style>
        button {
            background-color: #4CAF50;
            color: white;
            padding: 10px 15px;
            border: none;
            border-radius: 4px;
            cursor: pointer;
        }
        button:hover {
            background-color: #45a049;
        }
    </style>
    <button><slot>Clique aqui</slot></button>
</template>

<script>
    class MeuBotao extends HTMLElement {
        constructor() {
            super();
            const shadow = this.attachShadow({mode: 'open'});
            const template = document.getElementById('meu-botao-template');
            shadow.appendChild(template.content.cloneNode(true));
        }
    }
    
    customElements.define('meu-botao', MeuBotao);
</script>

<!-- Uso do web component -->
<meu-botao>Enviar</meu-botao>
<meu-botao>Cancelar</meu-botao>

Acessibilidade (ARIA)

ARIA (Accessible Rich Internet Applications) melhora a acessibilidade de aplicações web para pessoas com deficiências.

<!-- Exemplo de uso de ARIA -->
<div role="navigation" aria-label="Menu principal">
    <ul>
        <li><a href="#" aria-current="page">Home</a></li>
        <li><a href="#">Produtos</a></li>
        <li><a href="#">Contato</a></li>
    </ul>
</div>

<button aria-expanded="false" aria-controls="conteudo-expansivel">
    Mais informações
</button>
<div id="conteudo-expansivel" aria-hidden="true">
    Conteúdo adicional que pode ser expandido.
</div>

<div role="alert" aria-live="assertive">
    Este alerta será anunciado para usuários de leitores de tela.
</div>
