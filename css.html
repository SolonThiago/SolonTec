CSS Básico

O que é CSS?

CSS (Cascading Style Sheets) é uma linguagem usada para descrever a apresentação de documentos HTML. Controla o layout, cores, fontes e aparência visual dos elementos.

Como incluir CSS

Existem três maneiras de adicionar CSS a um documento HTML:

<!-- 1. CSS Inline -->
<p style="color: blue; font-size: 16px;">Este é um texto com estilo inline.</p>

<!-- 2. CSS Interno (no cabeçalho) -->
<head>
    <style>
        p {
            color: blue;
            font-size: 16px;
        }
    </style>
</head>

<!-- 3. CSS Externo (arquivo separado) -->
<head>
    <link rel="stylesheet" href="estilo.css">
</head>

Seletores CSS básicos

Os seletores determinam quais elementos HTML serão estilizados.

/* Seletor de elemento */
p {
    color: blue;
}

/* Seletor de classe */
.destaque {
    font-weight: bold;
    background-color: yellow;
}

/* Seletor de ID */
#cabecalho {
    background-color: black;
    color: white;
}

/* Seletor universal */
* {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
}

Propriedades CSS básicas

Algumas das propriedades CSS mais comuns para estilizar elementos:

/* Texto e Fonte */
p {
    color: #333;               /* Cor do texto */
    font-family: Arial, sans-serif; /* Tipo de fonte */
    font-size: 16px;           /* Tamanho da fonte */
    font-weight: bold;         /* Peso da fonte (normal, bold) */
    text-align: center;        /* Alinhamento (left, center, right) */
    line-height: 1.5;          /* Altura da linha */
    text-decoration: underline; /* Decoração (underline, none) */
}

/* Espaçamento e Dimensões */
div {
    width: 300px;              /* Largura */
    height: 200px;             /* Altura */
    margin: 10px;              /* Margem externa */
    padding: 20px;             /* Preenchimento interno */
}

/* Cores e Fundos */
section {
    background-color: #f0f0f0; /* Cor de fundo */
    border: 1px solid #ddd;    /* Borda */
    border-radius: 5px;        /* Borda arredondada */
    box-shadow: 2px 2px 5px rgba(0,0,0,0.1); /* Sombra */
}

CSS Intermediário

Box Model

O Box Model é um conceito fundamental do CSS que define como os elementos são renderizados na página.

div {
    width: 300px;
    height: 200px;
    padding: 20px;
    border: 1px solid black;
    margin: 10px;
    box-sizing: border-box; /* Faz width e height incluírem padding e border */
}

/* Box-sizing: border-box vs content-box */
.elemento1 {
    box-sizing: content-box; /* Padrão - width/height não incluem padding e border */
    width: 300px;
    padding: 20px;
    border: 1px solid black;
    /* Largura total: 300px + 40px (padding) + 2px (border) = 342px */
}

.elemento2 {
    box-sizing: border-box; /* width/height incluem padding e border */
    width: 300px;
    padding: 20px;
    border: 1px solid black;
    /* Largura total: 300px (conteúdo reduz de tamanho) */
}

Posicionamento

CSS oferece várias formas de posicionar elementos na página.

/* Position: static (padrão) */
.static {
    position: static;
    /* Não afetado por top, right, bottom, left */
}

/* Position: relative */
.relative {
    position: relative;
    top: 20px;
    left: 30px;
    /* Movido 20px para baixo e 30px para direita da posição normal */
}

/* Position: absolute */
.absolute {
    position: absolute;
    top: 0;
    right: 0;
    /* Posicionado no canto superior direito do elemento pai posicionado mais próximo */
}

/* Position: fixed */
.fixed {
    position: fixed;
    bottom: 10px;
    right: 10px;
    /* Fixo na viewport, não se move com a rolagem */
}

/* Position: sticky */
.sticky {
    position: sticky;
    top: 0;
    /* Comporta-se como relative até atingir a posição especificada na viewport */
}

Flexbox

Flexbox é um método de layout que facilita o posicionamento e alinhamento de elementos em uma dimensão.

/* Container Flex */
.container {
    display: flex;
    flex-direction: row;       /* row, column, row-reverse, column-reverse */
    justify-content: space-between; /* Alinhamento no eixo principal */
    align-items: center;       /* Alinhamento no eixo transversal */
    flex-wrap: wrap;           /* wrap, nowrap */
    gap: 10px;                 /* Espaçamento entre itens */
}

/* Itens Flex */
.item {
    flex: 1;                   /* Item cresce e encolhe igualmente */
    /* Ou especificar cada propriedade separadamente: */
    flex-grow: 1;              /* Fator de crescimento */
    flex-shrink: 1;            /* Fator de encolhimento */
    flex-basis: auto;          /* Tamanho inicial */
    
    align-self: flex-start;    /* Sobreescreve align-items para este item */
    order: 2;                  /* Ordem de exibição (padrão: 0) */
}

CSS Avançado

CSS Grid

CSS Grid é um sistema de layout bidimensional que permite criar layouts complexos com maior controle.

/* Container Grid */
.grid-container {
    display: grid;
    grid-template-columns: repeat(3, 1fr); /* 3 colunas de tamanho igual */
    grid-template-rows: 100px auto 100px; /* 3 linhas com alturas específicas */
    gap: 20px;                 /* Espaçamento entre células */
    
    /* Layout de áreas nomeadas */
    grid-template-areas: 
        "header header header"
        "sidebar content content"
        "footer footer footer";
}

/* Itens Grid */
.header {
    grid-area: header;         /* Define qual área nomeada este elemento ocupa */
}

.sidebar {
    grid-area: sidebar;
}

.content {
    grid-area: content;
}

.footer {
    grid-area: footer;
}

/* Posicionamento específico */
.item-especifico {
    grid-column: 1 / 3;        /* Ocupa da coluna 1 até coluna 3 */
    grid-row: 2 / 4;           /* Ocupa da linha 2 até linha 4 */
    /* Ou use span: */
    grid-column: 1 / span 2;   /* Começa na coluna 1 e ocupa 2 colunas */
}

Animações e Transições

CSS permite criar animações e transições suaves sem JavaScript.

/* Transições */
.elemento {
    background-color: blue;
    transition: background-color 0.5s ease, transform 0.3s ease-in-out;
}

.elemento:hover {
    background-color: red;
    transform: scale(1.1);
}

/* Animações */
@keyframes moverElemento {
    0% {
        transform: translateX(0);
        opacity: 0;
    }
    50% {
        opacity: 0.5;
    }
    100% {
        transform: translateX(100px);
        opacity: 1;
    }
}

.animado {
    animation-name: moverElemento;
    animation-duration: 2s;
    animation-timing-function: ease-in-out;
    animation-delay: 0.5s;
    animation-iteration-count: infinite;
    animation-direction: alternate;
    
    /* Forma abreviada: */
    animation: moverElemento 2s ease-in-out 0.5s infinite alternate;
}

CSS Variables (Custom Properties)

Variáveis CSS permitem armazenar e reutilizar valores, facilitando a manutenção e consistência.

/* Definindo variáveis globais */
:root {
    --cor-primaria: #3498db;
    --cor-secundaria: #2ecc71;
    --cor-texto: #333;
    --fonte-principal: 'Roboto', sans-serif;
    --espacamento-padrao: 20px;
}

/* Usando variáveis */
header {
    background-color: var(--cor-primaria);
    padding: var(--espacamento-padrao);
}

button {
    background-color: var(--cor-secundaria);
    color: white;
    font-family: var(--fonte-principal);
    border: none;
    padding: calc(var(--espacamento-padrao) / 2);
}

/* Variáveis em escopo local */
.componente {
    --componente-largura: 300px;
    width: var(--componente-largura);
}

/* Alterar variáveis com media queries */
@media (max-width: 768px) {
    :root {
        --espacamento-padrao: 10px;
    }
}

Design Responsivo Avançado

Técnicas avançadas para criar designs responsivos que funcionam bem em qualquer dispositivo.

/* Media Queries */
@media screen and (max-width: 768px) {
    /* Estilos para tablets e dispositivos menores */
    .container {
        flex-direction: column;
    }
}

@media screen and (max-width: 480px) {
    /* Estilos para smartphones */
    .menu {
        display: none;
    }
}

/* Unidades responsivas */
.container {
    width: 100%;
    max-width: 1200px;
    margin: 0 auto;
    padding: 0 5%;
}

.texto {
    font-size: clamp(16px, 3vw, 24px); /* Mínimo, preferido, máximo */
}

.hero {
    height: 100vh; /* Viewport height */
}

.imagem {
    width: 100%;
    object-fit: cover;
}
